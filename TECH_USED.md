# 🛠️ Tech Stack & Technologies Used

- **MediaPipe Hands**: Real-time 21 3D hand landmark tracking powered by WebAssembly & WebGL.
- **Vanilla JavaScript (ES2022)**: Custom 3D vector math, joint angle calculation, and gesture classification.
- **HTML5 Canvas 2D**: High-performance real-time skeletal wireframe overlay rendering.
- **Web Speech API**: Client-side text-to-speech (`SpeechSynthesis`) with smart debounce & cooldown.
- **MediaStreams API**: Direct webcam video stream capture via `getUserMedia()`.
- **HTML5 & Modern CSS3**: Responsive glassmorphism UI with dark/light mode and zero framework overhead.
- **Temporal Stabilization**: 7-frame sliding window buffer and hysteresis lock to eliminate jitter.
- **Node.js & Serve**: Lightweight local HTTP server for native ES module hosting.
- **Git & GitHub**: Version control and source code management.
